# Circular Patch Antenna Design and Simulation at 2.45 GHz Using CST Studio Suite

## 📌 Project Overview

This project focuses on the design and simulation of a Circular Patch Antenna operating at 2.45 GHz using CST Studio Suite.

The antenna is modeled and simulated to study its electromagnetic characteristics and evaluate its suitability for wireless communication applications. The project involves creating the substrate and conducting patch structures and setting up the antenna model for electromagnetic analysis.

## 🎯 Objectives

- Design a circular microstrip patch antenna operating at 2.45 GHz.
- Create the antenna geometry using CST Studio Suite.
- Define the substrate and conductive patch materials.
- Configure the antenna model for electromagnetic simulation.
- Analyze antenna performance at the target frequency.
- Explore the antenna's potential applications in wireless communication.

## 🛠️ Software Used

- CST Studio Suite
- Electromagnetic Simulation and Antenna Design Tools

## ⚙️ Design Methodology

### 1. Antenna Modeling
The antenna geometry is created in CST Studio Suite by defining the required dimensions and parameters.

### 2. Substrate Design
The substrate is modeled with specified dimensions and an appropriate dielectric material.

### 3. Conducting Patch Design
The conducting patch and other required metallic structures are created using copper.

### 4. Simulation Setup
The simulation environment is configured to analyze the antenna's electromagnetic behavior around the target operating frequency of 2.45 GHz.

### 5. Performance Analysis
The simulation results can be used to evaluate parameters such as:

- Return Loss (S11)
- Voltage Standing Wave Ratio (VSWR)
- Resonant Frequency
- Bandwidth
- Radiation Pattern
- Gain and Directivity

## 📊 Expected Outcomes

The project aims to develop a circular patch antenna model designed for operation near 2.45 GHz.

Simulation results can help evaluate the antenna's performance and determine whether its resonant frequency and impedance characteristics meet the design requirements.

**Note:** Actual performance depends on the antenna dimensions, substrate properties, feed configuration, and simulation settings. Numerical results should be added after completing the simulation.
